## Project-Specific Tasks

### R1 — Accept User Name Input

- [x] In `app/agent.py`, update the system prompt to instruct the agent to extract the user's name from any incoming message
- [x] Handle the edge case: if no name is detectable, use a friendly default (e.g. "friend") rather than failing

### R2 — Generate Personalized Greeting

- [x] The system prompt must instruct the agent to produce a warm, personalized greeting that includes the user's name
- [x] The greeting must be generated via an LLM call (no hard-coded strings)
- [x] The response must contain the name provided in the input

### R3 — Return Response via A2A Protocol

- [x] Verify the agent's response is returned as a properly structured A2A streaming response (the bootstrap handles this; confirm it is not broken)
- [x] Confirm `/.well-known/agent.json` is accessible and valid after startup

### R4 — No External Tools (Hello World Baseline)

- [x] This agent has NO MCP tool dependencies — do not add any `requires` entries to `asset.yaml`
- [x] Do not wire any MCP tool loading; `get_mcp_tools()` should return an empty list (or be omitted)
- [x] This keeps the template minimal and dependency-free for reuse
